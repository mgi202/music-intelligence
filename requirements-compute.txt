# Music Intelligence System — compute node ONLY (Phase 3 "Ears").

# Installed INSIDE the compute-node Docker image (compute_node/Dockerfile,
# linux/amd64) — NEVER into the server image, CI, or requirements.txt.
# torch/torchaudio are installed separately in the Dockerfile from the
# PyTorch CPU index (the default index pulls multi-GB CUDA builds).

# Notes:
# - essentia-tensorflow publishes manylinux x86_64 wheels only (no aarch64) —
#   that is why the image is linux/amd64 under Rosetta on Apple Silicon.
#   macOS arm64 wheels exist but the native pip path is broken
#   (MTG/essentia#1486); don't "simplify" back to a host venv.
# - numpy<2 is required by laion-clap (1.1.7: numpy>=1.23.5,<2).
# - pysocks lets requests use the in-container tailscaled SOCKS proxy
#   (MIS_PROXY) for server calls.
